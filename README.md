🚀 ElevateCV AI – AI Career Coach & ATS Analyzer

Transform Your Job Search With AI-Powered Career Intelligence

An end-to-end web application that equips job seekers with instant ATS resume scoring, document text extraction, specialized AI interview coaching, and real-time skill performance tracking.

🌟 Overview

ElevateCV AI is designed to give job applicants a competitive edge in today's automated hiring process. Featuring a modern, glassmorphic dark-mode interface, the platform provides automated ATS optimization, client-side document processing, dynamic interview prep tailored to specific roles, and real-time performance metrics.

✨ Key Features

📄 1. ATS Resume Analyzer

📂 Multi-Format Uploads: Directly process .pdf, .docx, and .txt files on the client side using pdf.js and mammoth.js.

📊 ATS Match Score: Get an instant numeric score out of 100 based on modern recruitment criteria.

💡 Actionable Insights: Receives executive summaries, structural strengths, and recommended improvements to pass automated screeners.

🤖 2. AI Interview Coach

🎯 Domain-Specific Questioning: Covers Software Engineering, Frontend, Product Management, Data Science, DevOps, Cyber Security, System Design, and HR.

⚙️ Tailored Configurations: Customize questions by:

Seniority Level: Internship ➔ Executive

Interview Mode: Behavioral (STAR), Technical Deep-Dive, System Design, HR & Culture Fit

Focus Topic: Custom inputs (e.g., React, Microservices, Kubernetes)

📝 Detailed Feedback Engine: Ratings out of 10 broken down by Communication and Technical Depth, accompanied by key strengths, growth points, and ideal sample answers.

📈 3. Live Performance Dashboard

Track your readiness across 4 core vectors:

💬 Communication & Structure

💻 Technical Proficiency

🧠 Problem Solving Depth

🎯 ATS Keyword Relevance

🛠️ Tech Stack

Frontend: HTML5, CSS3 (Modern Glassmorphism), JavaScript (ES6+)

UI Components & Fonts: Plus Jakarta Sans, Lucide Icons

Document Parsers: PDF.js (PDF extraction), Mammoth.js (DOCX extraction)

Backend API: Node.js / Express (Listening on port 5000)

🚀 Quick Start
